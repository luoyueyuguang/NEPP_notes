\section{图}

课程之间的先修关系、城市之间的公路网、网络中数据包的转发路径，都可以抽象成同一类对象：用点表示事物，用线表示事物之间的联系。点之间的线有没有方向、带不带权值，决定了后续该用哪种算法。本章从这种抽象出发，先说明图怎么存，再讨论怎么遍历，最后处理最小生成树、最短路径、拓扑排序和关键路径这几类典型问题。

\subsection{图的基本概念}

一个图记作 $G=(V,E)$。$V$ 是顶点集，$E$ 是边集。$|V|=n$ 称为图的阶，$|E|=e$ 是边数。边没有方向时写作 $(u,v)$，称为无向边；边有方向时写作 $\langle u,v\rangle$，称为弧，$u$ 是弧尾，$v$ 是弧头。既没有自环、也没有重边的图称为简单图；本章默认讨论简单图。

若任意两个顶点之间都有边，称为完全图。无向完全图 $K_n$ 的边数是
\[
\binom{n}{2}=\frac{n(n-1)}{2},
\]
有向完全图每对顶点之间有两个方向的弧，弧数为 $n(n-1)$。这两个数给出了简单图边数的上界。

\subsubsection{度、路径与连通}

无向图中，与顶点 $v$ 关联的边数称为 $v$ 的度，记作 $\deg(v)$。有向图把度拆成入度和出度：以 $v$ 为弧头的弧数是入度 $\operatorname{id}(v)$，以 $v$ 为弧尾的弧数是出度 $\operatorname{od}(v)$。每条无向边有两个端点，每条弧有一个弧尾和一个弧头，因此
\[
\sum_{v\in V}\deg(v)=2e,
\qquad
\sum_{v\in V}\operatorname{id}(v)
=\sum_{v\in V}\operatorname{od}(v)=e.
\]
第一条式子常称为握手定理。它有一个直接推论：度数为奇数的顶点个数一定是偶数。

顶点序列 $v_0,v_1,\ldots,v_k$ 中，若相邻两项之间都有边，则称它为一条路径，路径上边的数目 $k$ 是路径长度。顶点不重复的路径称为简单路径。起点和终点相同的路径称为回路；除起点终点外顶点不重复的回路称为简单回路。

无向图中，若 $u$ 到 $v$ 存在路径，称 $u$ 与 $v$ 连通。任意两个顶点都连通的图称为连通图。连通图的极大连通子图就是它本身；非连通图可以分成若干个连通分量。这里的“极大”指不能再加入顶点或边而保持连通。有向图对应的概念是强连通：任意两个顶点互相可达。强连通图的极大强连通子图称为强连通分量。

连通图的生成树，是包含全部 $n$ 个顶点、恰好 $n-1$ 条边的连通子图。它连通且没有回路，去掉任意一条边都会变成非连通图，因此是“极小连通子图”。非连通图有 $k$ 个连通分量时，每个分量各取一棵生成树，合起来称为生成森林，共 $n-k$ 条边。

\subsection{图的存储}

图有两种最常用的存法。邻接矩阵关心“任意两点之间有没有边”，邻接表关心“每个点连出去哪些边”。选用哪一种，取决于图是稠密还是稀疏，以及算法需要频繁做哪类查询。

\subsubsection{邻接矩阵}

设顶点编号为 $v_0,v_1,\ldots,v_{n-1}$。邻接矩阵 $A$ 是 $n\times n$ 的矩阵。无权图中
\[
A[i][j]=
\begin{cases}
1, & (v_i,v_j)\in E \text{ 或 } \langle v_i,v_j\rangle\in E,\\
0, & \text{否则}.
\end{cases}
\]
带权图把 $1$ 换成边权 $w_{ij}$；没有边时填 $\infty$，而不是 $0$。这一点在最短路径里很关键：$0$ 是合法的边权，用它表示“没有边”会让松弛过程把不存在的边当成权值为 $0$ 的边。

邻接矩阵的优缺点很直接。空间是 $O(n^2)$，适合边数接近 $n^2$ 的稠密图。判断 $(v_i,v_j)$ 是否有边只需读一个单元，时间 $O(1)$。无权图中，无向图顶点 $v_i$ 的度就是第 $i$ 行非零元的个数；有向图的出度是行和，入度是列和。带权图不能直接对行求和来求度，要先数不等于 $\infty$ 的元素。代价是，遍历一个顶点的所有邻边要扫描整行，时间是 $O(n)$，与它实际连了多少条边无关。

对无权图，邻接矩阵还有一个性质：$A^k[i][j]$ 等于从 $v_i$ 到 $v_j$、长度为 $k$ 的走法数。这里的走法允许重复经过顶点和边，不能把它当成简单路径的条数。

邻接表的空间是 $O(n+e)$，适合稀疏图。求无向图中顶点 $v$ 的度，只需数它链表的结点个数，时间是 $O(\deg(v))$。求有向图的出度同样方便；求入度则要扫描全部链表，或者另外建一张逆邻接表。判断 $(u,v)$ 是否存在也要沿着 $u$ 的链表找，时间是 $O(\deg(u))$。邻接表不唯一：同一条链表里，结点的先后顺序可以不同，所以同一张图可以写出多种邻接表。

后文的 \texttt{MGraph} 指邻接矩阵，\texttt{ALGraph} 指邻接表，\texttt{ArcNode} 是邻接表中的边结点。

此外还有两种改进结构。十字链表用于有向图：顶点结点存 \texttt{data}、\texttt{firstin}、\texttt{firstout}，弧结点存 \texttt{tailvex}、\texttt{headvex}、\texttt{weight}、\texttt{hlink}、\texttt{tlink}。一条弧同时挂进“同弧尾”和“同弧头”两条链，因此出度和入度都能顺着链求。邻接多重表用于无向图：每条边只建一个结点，存 \texttt{ivex}、\texttt{jvex}、\texttt{ilink}、\texttt{jlink}，两个端点各自把这条边挂进自己的链。它避免了邻接表中一条无向边存两次的问题，删除边也更方便。

\subsection{图的遍历}

遍历图是从某个顶点出发，沿边走到所有能到达的顶点，并且每个顶点只访问一次。和树的遍历不同，图里可能有回路，所以必须用一个 \texttt{visited} 数组记录已经访问过的顶点，否则会在回路里打转。

\subsubsection{广度优先搜索}

广度优先搜索（BFS）按“离起点的边数”分层访问。先访问起点，再访问所有与起点直接相邻的顶点，然后访问距离为 2 的顶点，依此类推。实现时用一个队列保存“已经发现、但还没有扩展其邻边”的顶点。

\begin{lstlisting}[language=C]
void BFS(ALGraph *G, int s) {
    bool visited[MaxV] = {false};
    int queue[MaxV], front = 0, rear = 0;
    visited[s] = true;
    queue[rear++] = s;
    while (front < rear) {
        int u = queue[front++];
        visit(u);
        for (ArcNode *p = G->adjlist[u].first; p; p = p->next) {
            int v = p->adjvex;
            if (!visited[v]) {
                visited[v] = true;      // 入队时就标记，避免重复入队
                queue[rear++] = v;
            }
        }
    }
}
\end{lstlisting}

入队时立刻置 \texttt{visited[v]=true}，而不是等出队时再标记。否则同一个顶点可能被多个前驱重复放入队列。

BFS 有一个重要性质：在无权图中，BFS 首次访问顶点 $v$ 时经过的边数，就是起点到 $v$ 的最短路径长度。因为 BFS 严格按层扩展，距离为 $k$ 的顶点全部处理完，才会处理距离为 $k+1$ 的顶点。把 BFS 过程中“首次发现顶点”的边留下来，就得到 BFS 生成树；非连通图从每个未访问顶点各做一次 BFS，得到 BFS 生成森林。

\subsubsection{深度优先搜索}

深度优先搜索（DFS）沿一条路一直走，走到不能再走时回溯，换一个分支继续。递归写法最自然。

\begin{lstlisting}[language=C]
bool visited[MaxV];
void DFS(ALGraph *G, int v) {
    visited[v] = true;
    visit(v);
    for (ArcNode *p = G->adjlist[v].first; p; p = p->next)
        if (!visited[p->adjvex])
            DFS(G, p->adjvex);
}
\end{lstlisting}

DFS 的递归深度最多为 $n$，栈空间是 $O(n)$。和 BFS 一样，DFS 过程中首次到达某个顶点所用的边构成 DFS 生成树。指向祖先的非树边称为回边；在无向图中，非树边一定是回边；在有向图中还可能出现指向已完成顶点的前向边或横叉边。无向图中遇到回边说明存在回路；有向图中回边指向当前递归栈里的祖先，同样说明存在有向回路。

\begin{center}
\begin{tabular}{lcc}
\toprule

\midrule
辅助结构 & 队列 & 栈（或递归） \\
访问顺序 & 按层扩展 & 沿路径深入，走不通再回溯 \\
生成树 & 根到顶点的路径边数最少 & 不保证边数最少 \\
典型用途 & 无权最短路、分层 & 连通性、回路、拓扑排序 \\
时间复杂度 & $O(n+e)$ 或 $O(n^2)$ & $O(n+e)$ 或 $O(n^2)$ \\
\bottomrule
\end{tabular}
\end{center}

两种遍历的时间复杂度相同。邻接表存储时，每个顶点访问一次，每条边扫描一次（无向图两次），总计 $O(n+e)$。邻接矩阵存储时，每访问一个顶点都要扫描它的一整行，总计 $O(n^2)$。

遍历序列是否唯一，取决于题目有没有规定起点和邻接点的扫描顺序。即使用邻接矩阵，若从不同顶点出发，序列也会不同；用邻接表时，链表里结点的顺序还会影响序列。考试中若要比较两个序列，先看清题目给出的起点和“按编号递增”之类的规则。

\begin{attention}
BFS 能求无权图的最短路径，DFS 不能。DFS 找到的路径只保证是一条可行路径，不保证边数最少。反过来，DFS 更适合判断回路、求强连通分量、做拓扑排序；BFS 更适合分层和求最少边数。
\end{attention}

\subsection{最小生成树}

在一个连通带权无向图中，生成树有很多棵。边权之和最小的那棵称为最小生成树（Minimum Spanning Tree，MST）。例如要在 $n$ 个城市之间铺光缆，要求任意两城连通且总长度最短，就是在求 MST。

MST 可能不唯一。比如一个三角形的三条边权都是 1，任意去掉一条边都能得到一棵 MST。但所有 MST 的总权值相同。若图中所有边权互不相同，MST 唯一。

求 MST 的两种经典算法都基于同一个事实：对图的任意一个割（把顶点分成两个非空集合），横跨这个割的最小权边一定属于某棵 MST。这条性质称为割性质。Prim 算法每次选一个割，Kruskal 算法则从全局最小的边开始，用并查集判断会不会成环。

\subsubsection{Prim 算法}

Prim 算法维护一个已经加入树的顶点集合 $S$。初始时 $S$ 只含起点。每一轮，在“一个端点在 $S$ 内、另一个端点在 $S$ 外”的边中选权值最小的一条，把外面的顶点加入 $S$。重复 $n-1$ 轮，就得到一棵生成树。

\begin{lstlisting}[language=C]
void Prim(MGraph G, int s) {
    int lowcost[MaxV], closest[MaxV];
    bool inTree[MaxV] = {false};
    for (int i = 0; i < G.n; i++) {
        lowcost[i] = G.edges[s][i];   // i 到当前树的最小边权
        closest[i] = s;               // 该边在树内的端点
    }
    inTree[s] = true;
    lowcost[s] = 0;
    for (int k = 1; k < G.n; k++) {
        int u = -1, min = INF;
        for (int i = 0; i < G.n; i++)
            if (!inTree[i] && lowcost[i] < min) {
                min = lowcost[i]; u = i;
            }
        if (u == -1) return;          // 图不连通
        inTree[u] = true;
        for (int i = 0; i < G.n; i++)
            if (!inTree[i] && G.edges[u][i] < lowcost[i]) {
                lowcost[i] = G.edges[u][i];
                closest[i] = u;
            }
    }
}
\end{lstlisting}

\texttt{lowcost[i]} 始终表示顶点 $i$ 到当前树 $S$ 的最小边权，\texttt{closest[i]} 记录这条最小边在树内的端点。选中最小的 \texttt{lowcost[u]} 后，把 $u$ 加入树，再用 $u$ 的出边更新其他顶点的 \texttt{lowcost}。

用邻接矩阵实现时，每轮找最小值和更新各需 $O(n)$，共 $n-1$ 轮，时间复杂度 $O(n^2)$。这个复杂度只和顶点数有关，和边数无关，所以 Prim 适合稠密图。用邻接表和堆优化可以做到 $O(e\log n)$，但 408 更常考 $O(n^2)$ 的数组版本。

\subsubsection{Kruskal 算法}

Kruskal 算法把所有边按权值从小到大排序，依次检查。若当前边的两个端点属于不同的连通分量，就加入这条边；否则加入会成环，直接舍弃。选够 $n-1$ 条边时停止。

判断两个端点是否属于同一分量，用并查集。初始时每个顶点各自成一个集合，加入一条边就合并两个集合。排序是主要开销，时间复杂度 $O(e\log e)$；并查集的操作近似常数。Kruskal 的时间主要花在边数上，适合稀疏图。

\subsection{最短路径}

最短路径问题分两种：单源最短路径求一个起点到其余各点的最短路径；全源最短路径求任意两点之间的最短路径。边权可以为负，但本章默认不含负权回路；有负权回路时，绕回路可以无限减小路径长度，最短路径不存在。

\subsubsection{无权图：BFS}

无权图可以把每条边看成权值为 1。此时 BFS 按层扩展，首次到达某顶点经过的边数就是最短路径长度。BFS 生成树上从起点到顶点的路径就是一条最短路径。这个方法时间是 $O(n+e)$，比直接套用带权算法更简单。

\subsubsection{Dijkstra 算法}

Dijkstra 算法处理非负边权的单源最短路径。它维护一个已经确定最短距离的顶点集合 $S$，以及数组 $d[i]$，表示目前找到的从源点到 $i$ 的最短距离。每轮从未确定的顶点中选 $d$ 最小的那个，把它加入 $S$，再用它的出边松弛其他顶点。

\begin{lstlisting}[language=C]
void Dijkstra(MGraph G, int s, int dist[], int path[]) {
    bool final[MaxV] = {false};
    for (int i = 0; i < G.n; i++) {
        dist[i] = G.edges[s][i];
        path[i] = (dist[i] < INF) ? s : -1;
    }
    dist[s] = 0; final[s] = true; path[s] = -1;
    for (int k = 1; k < G.n; k++) {
        int u = -1, min = INF;
        for (int i = 0; i < G.n; i++)
            if (!final[i] && dist[i] < min) {
                min = dist[i]; u = i;
            }
        if (u == -1) break;           // 剩余顶点不可达
        final[u] = true;
        for (int i = 0; i < G.n; i++)
            if (!final[i] && dist[u] + G.edges[u][i] < dist[i]) {
                dist[i] = dist[u] + G.edges[u][i];
                path[i] = u;
            }
    }
}
\end{lstlisting}

\texttt{path[i]} 记录最短路径上 $i$ 的前驱。求完整路径时从终点沿 \texttt{path} 往回走，直到源点，再反过来输出。

Dijkstra 与 Prim 的代码结构很像，区别在数组含义。Prim 的 \texttt{lowcost[i]} 是 $i$ 到当前树的一条边权；Dijkstra 的 \texttt{dist[i]} 是源点到 $i$ 的整条路径长度。更新时，Prim 用 $w(u,i)$ 直接比较，Dijkstra 用 \texttt{dist[u]}+$w(u,i)$ 比较。

邻接矩阵实现的时间复杂度是 $O(n^2)$，适合稠密图。用邻接表加优先队列可以做到 $O((n+e)\log n)$。408 选择题常要求手算每一轮的 $d$ 数组，下面用一个具体例子走一遍。

\subsubsection{Floyd 算法}

Floyd 算法求任意两点之间的最短路径。它用动态规划，把“允许经过哪些顶点作为中转”作为阶段。定义 $D^{(k)}[i][j]$ 为：从 $v_i$ 到 $v_j$，只允许把 $v_0,v_1,\ldots,v_k$ 当作中转点时的最短路径长度。这里的“中转点”不包含起点和终点本身。

初始时 $D^{(0)}$ 就是邻接矩阵：要么是直达边的权值，要么是 $\infty$。加入第 $k$ 个中转点后，从 $i$ 到 $j$ 的路径只有两种可能：不经过 $v_k$，长度是 $D^{(k-1)}[i][j]$；经过 $v_k$，长度是 $D^{(k-1)}[i][k]+D^{(k-1)}[k][j]$。取较小者：
\[
D^{(k)}[i][j]
=\min\left(D^{(k-1)}[i][j],\;
D^{(k-1)}[i][k]+D^{(k-1)}[k][j]\right).
\]
$k$ 从 $0$ 到 $n-1$ 循环，最后的 $D^{(n)}$ 就是全源最短路径长度矩阵。

\begin{lstlisting}[language=C]
void Floyd(MGraph G, int D[][MaxV], int path[][MaxV]) {
    for (int i = 0; i < G.n; i++)
        for (int j = 0; j < G.n; j++) {
            D[i][j] = G.edges[i][j];
            path[i][j] = (D[i][j] < INF && i != j) ? i : -1;
        }
    for (int k = 0; k < G.n; k++)
        for (int i = 0; i < G.n; i++)
            for (int j = 0; j < G.n; j++)
                if (D[i][k] + D[k][j] < D[i][j]) {
                    D[i][j] = D[i][k] + D[k][j];
                    path[i][j] = path[k][j];
                }
}
\end{lstlisting}

三个循环的顺序不能随意交换。$k$ 必须在最外层：每一轮只允许加入一个新的中转点，三轮循环分别固定“阶段、起点、终点”。如果把 $k$ 放到最内层，某些需要多个中转点的路径会在错误的阶段被更新，结果可能偏大。$D$ 可以在原地更新，因为第 $k$ 轮中 $D[i][k]$ 和 $D[k][j]$ 都不会改变：它们对应的路径不允许把 $v_k$ 当中转点，加入 $v_k$ 不会让它们更短（前提是没有负权回路）。

时间复杂度 $O(n^3)$，空间 $O(n^2)$。Floyd 允许负权边，但不能有负权回路。运行结束后若某个 $D[i][i]<0$，说明存在从 $i$ 出发又回到 $i$ 的负权回路，最短路径无意义。

\subsection{拓扑排序}

有向无环图（DAG）常用于表示“谁必须在谁之前完成”。例如课程 $A$ 是课程 $B$ 的先修课，就从 $A$ 向 $B$ 连一条弧。把这种图的所有顶点排成一个线性序列，使得每条弧的弧尾都排在弧头之前，这个序列称为拓扑序列，求序列的过程称为拓扑排序。

拓扑序列不唯一：算法在某一步可能同时有多个入度为 0 的顶点，先输出哪一个都可以。两个没有路径关系的顶点，在不同拓扑序列中的先后可以不同；但在同一个序列里任意交换两个不相邻的顶点，可能会破坏别的约束。一个 DAG 的拓扑序列唯一，当且仅当它在每一步都只有一个入度为 0 的顶点；等价地说，图中存在一条经过所有顶点的有向路径。

\subsubsection{基于入度的 Kahn 算法}

Kahn 算法反复做两件事：输出一个入度为 0 的顶点；删除它的所有出边，并把终点的入度减 1。删边后可能出现新的入度为 0 的顶点，把它加入队列。若最终输出的顶点数小于 $n$，说明剩下的顶点都有入边，图中存在有向回路。

\begin{lstlisting}[language=C]
bool TopoSort(ALGraph *G, int topo[]) {
    int indeg[MaxV] = {0}, cnt = 0;
    for (int u = 0; u < G->n; u++)
        for (ArcNode *p = G->adjlist[u].first; p; p = p->next)
            indeg[p->adjvex]++;
    int queue[MaxV], front = 0, rear = 0;
    for (int i = 0; i < G->n; i++)
        if (indeg[i] == 0) queue[rear++] = i;
    while (front < rear) {
        int u = queue[front++];
        topo[cnt++] = u;
        for (ArcNode *p = G->adjlist[u].first; p; p = p->next)
            if (--indeg[p->adjvex] == 0)
                queue[rear++] = p->adjvex;
    }
    return cnt == G->n;       // false 表示有回路
}
\end{lstlisting}

用邻接表时，计算入度要扫描所有边，之后每个顶点入队、出队一次，每条边被处理一次，总时间 $O(n+e)$。用栈代替队列也能得到拓扑序列，只是输出次序不同。下一小节的 DFS 方法从另一个角度得到拓扑序：先递归到最深处，回溯时把顶点压栈，最后从栈顶依次弹出。

\subsubsection{基于 DFS 的方法}

对 DAG 做 DFS，记录每个顶点“完成”的次序。一个顶点完成时，它的所有后继都已经完成，所以按完成时间从晚到早排列，就得到拓扑序列。实现时把顶点在回溯阶段压入栈，最后依次弹出即可。

DFS 还能同时判断回路：如果从 $u$ 出发的 DFS 遇到一个仍在递归栈中的顶点 $v$，说明存在树边路径 $v\to\cdots\to u$，再加上回边 $u\to v$，构成有向回路。用一个颜色数组区分“未访问、在栈中、已完成”三种状态即可。

\subsection{AOE 网与关键路径}

AOV 网（Activity On Vertex）用顶点表示活动，用弧表示活动之间的先后关系，拓扑排序解决的是“活动按什么顺序做”。AOE 网（Activity On Edge）换一种表示：弧表示活动，弧上的权表示活动持续时间，顶点表示事件，即某些活动完成或开始的时刻。AOE 网通常只有一个源点（开始事件）和一个汇点（结束事件），源点入度为 0，汇点出度为 0。

关键路径是 AOE 网中从源点到汇点的最长路径，它的长度就是整个工程的最短工期。路径越长，说明这条链上的活动越不能拖延。要找出关键路径，需要计算每个事件的最早发生时间和最迟发生时间。

\subsubsection{事件的最早、最迟发生时间}

设 $ve(k)$ 是事件 $v_k$ 的最早发生时间。源点的 $ve$ 为 0。其他事件必须等所有前驱活动完成才能发生，所以
\[
ve(k)=\max_{\langle v_j,v_k\rangle\in E}\left\{ve(j)+w(j,k)\right\}.
\]
按拓扑序从左往右算，计算 $v_k$ 时它的所有前驱都已经算好。

设 $vl(k)$ 是事件 $v_k$ 的最迟发生时间，即在不推迟整个工期的前提下，事件最迟可以在什么时刻发生。汇点的 $vl$ 等于它的 $ve$，也就是总工期。其他事件必须给所有后继活动留出足够时间，所以
\[
vl(k)=\min_{\langle v_k,v_j\rangle\in E}\left\{vl(j)-w(k,j)\right\}.
\]
按逆拓扑序从右往左算，计算 $v_k$ 时它的所有后继都已经算好。

\subsubsection{活动的最早、最迟开始时间}

对活动 $a=\langle v_i,v_j\rangle$，它的最早开始时间等于弧尾事件的最早发生时间：
\[
e(a)=ve(i).
\]
它的最迟开始时间等于弧头事件的最迟发生时间减去活动持续时间：
\[
l(a)=vl(j)-w(i,j).
\]
两者之差 $l(a)-e(a)$ 是活动的时间余量，也叫松弛时间。若 $l(a)=e(a)$，说明这个活动没有任何余量，推迟一天就会推迟整个工程，称为关键活动。由关键活动首尾相接、从源点通到汇点的路径就是关键路径。

关于关键路径，有几个结论经常出现在选择题里。

\begin{itemize}
  \item 关键路径是源点到汇点的最长路径，长度等于最短工期。
  \item 关键路径可能不唯一。只缩短其中一条路径上的非公共活动，另一条关键路径的长度不变，总工期也不变。
  \item 要缩短总工期，必须缩短所有关键路径的公共关键活动；若几条关键路径没有公共活动，就要同时缩短每条关键路径上的活动。
  \item 缩短非关键活动一般不能缩短工期；一旦缩短量超过它的时间余量，它自己也会变成关键活动，需要重新判断关键路径。
\end{itemize}

\subsection{本章算法对照}

把本章的算法放在一起比较，考试时更容易选对方法。

\begin{center}
\small
\begin{tabular}{llll}
\toprule
算法 & 解决的问题 & 适用条件 & 时间复杂度 \\
\midrule
BFS & 无权图单源最短路、分层遍历 & 边权相同 & $O(n+e)$（邻接表） \\
DFS & 连通性、回路判定、拓扑排序 & 无特殊限制 & $O(n+e)$（邻接表） \\
Prim & 最小生成树 & 连通无向带权图 & $O(n^2)$，适合稠密图 \\
Kruskal & 最小生成树 & 连通无向带权图 & $O(e\log e)$，适合稀疏图 \\
Dijkstra & 单源最短路 & 边权非负 & $O(n^2)$ 或 $O((n+e)\log n)$ \\
Floyd & 全源最短路 & 允许负权，无负权回路 & $O(n^3)$ \\
Kahn & 拓扑排序 & 有向图，可判回路 & $O(n+e)$ \\
关键路径 & 工程最短工期 & AOE 网，DAG & $O(n+e)$ \\
\bottomrule
\end{tabular}
\end{center}

还有几个容易混淆的计数结论：

\begin{itemize}
  \item 连通无向图至少有 $n-1$ 条边；$n$ 个顶点的树恰好有 $n-1$ 条边。
  \item 强连通有向图（$n\geqslant 2$）至少有 $n$ 条弧，因为每个顶点至少要有一条出弧和一条入弧。
  \item 无向图中所有顶点度数之和为 $2e$，奇度顶点有偶数个。
  \item 邻接表存无向图有 $2e$ 个边结点，存有向图有 $e$ 个边结点。
  \item 拓扑序列一般不唯一；当且仅当每一步只有一个入度为 0 的顶点时，序列唯一。
\end{itemize}
