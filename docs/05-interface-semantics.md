# 05 · 接口语义文档（LaTeX 环境与命令）

> 本文档是仓库自定义 LaTeX 环境/命令的"接口语义"参考：每个接口说明用途、入参、输出与使用约束。
> 采用 `【接口：xxx】` 引用格式，方便其他文档引用。只收录在 `00`–`04` 文档中已提到的接口。

## 1. 知识框接口（两书共用语义）

### 【接口：定义框 mydef】
- **调用方**：章节文件（内容编写者）。
- **功能**：输出"定义"语义框——精确陈述概念，是知识体系的地基。
- **入参**：`{标题}{label}`——标题显示在框首，label 用于 `\ref` 引用（须全局唯一）。
- **输出**：带编号（`number within=section`）的彩色 tcolorbox，编号跟随节。
- **约束**：内容应只含定义本身；与公式/结论重复的定义会被 REVIEW 视为冗余。

### 【接口：公式框 formula】
- **调用方**：章节文件。
- **功能**：输出"公式/要点"语义框——可直接套用的结论、性质列表。
- **入参**：`{标题}{label}`。
- **输出**：数学侧粉色调、408 侧琥珀色调的要点框，可跨页（`breakable`）。
- **约束**：必须给出适用条件（REVIEW 曾集中补齐"极限四则运算、等价无穷小、L'Hospital 的适用条件"）。

### 【接口：结论框 conclusion】
- **调用方**：章节文件。
- **功能**：输出"结论"语义框——由定义+公式推出的可核验结果，含算法步骤、复杂度分析。
- **入参**：`{标题}{label}`。
- **输出**：数学侧蓝黑框、408 侧 Navy 左线框。
- **约束**：结论须可被正文推导支撑；"过强断言"（如"必考"、无条件的绝对表述）会被 REVIEW 修正。

### 【接口：注意事项框 attention】（仅 408）
- **调用方**：章节文件。
- **功能**：输出标题为"注意"的警示框，承载"408 常考陷阱"、易错辨析。
- **入参**：无（环境体直接用）。
- **输出**：琥珀色警示框。
- **约束**：每条警示须具体可操作；REVIEW 曾把"没有中断就没有进程切换"等绝对化表述改弱。

### 【接口：例题框 examplebox】（仅 408）
- **调用方**：章节文件。
- **功能**：承载带完整解法的例题（区别于习题区的练习题）。
- **入参**：无。
- **输出**：灰底例题框。
- **约束**：例题解法属于正文知识的一部分，**不受** `\ifshowsolutions` 控制——只有习题区的解析块受控。

### 【接口：表格框 tablebox】
- **调用方**：章节文件、模拟卷。
- **功能**：输出带标题的对照表（操作语义表、分布表、公式对照表等）。
- **入参**：`{标题}`（math 侧）+ 可选项。
- **输出**：teal/Navy 表头表格框。
- **约束**：宽表需自行保证不溢出（408 曾集中整改宽表溢出）。

## 2. 全局控制接口

### 【接口：解析开关 showsolutions】
- **调用方**：入口文件（唯一权威定义点）；章节/模拟卷文件（消费方）。
- **功能**：全局控制所有解析/答案的显隐。`true` → 题目+解析；`false` → 纯题目（解析处输出 `\answerarea` 书写留白）。
- **入参**：无；通过 `\showsolutionstrue` / `\showsolutionsfalse` 赋值。
- **输出**：`true` 时解析原样进入页面流；`false` 时 `\ifshowsolutions <解> \else \answerarea \fi` 展开为留白区。
- **约束**：
  1. 只在各自 `main.tex` 定义一次（`\newif`）；
  2. 任何子文件不得重复定义或赋值——历史教训见 408 REVIEW §6.1；
  3. 所有解析块必须无条件服从全局开关；
  4. 书写的留白宏 `\answerarea` 由 `main.tex` 统一定义，仅供 `\else` 分支调用，完整版自动跳过。

### 【接口：书写留白 answerarea】
- **调用方**：仅通过每个解析块的 `\else` 分支（`\showsolutionsfalse` 时）。
- **功能**：在题目后输出若干条灰线，给做题留出手写空间。`\answerarea[N]` 可指定横线条数。
- **入参**：可选参数 `[N]`（横线条数，默认 3）。章节选择题/填空题默认 3 条；模拟卷解答题/综合题用 `\answerarea[8]` 留出更多作答空间。
- **输出**：N 条 `\rule{\linewidth}{0.4pt}` 书写横线（`\foreach` 生成）。
- **约束**：不可独立使用；必须位于 `\ifshowsolutions` 的 `\else` 分支内。

### 【接口：例题标记 boxed解】
- **调用方**：章节文件习题区（math 侧为主）。
- **功能**：`\boxed{\textbf{解}}` 标记解析块起始，与 `\fi%` 配对构成完整的条件块。
- **入参**：无。
- **输出**：带框的"解"字标题。
- **约束**：必须位于 `\ifshowsolutions%` 之后、`\fi%` 之前；块内不得出现未配对的环境。

## 3. 版式接口（408 侧）

### 【接口：自定义封面 makecustomcover】
- **调用方**：`408/main.tex` 的 `\begin{document}` 首行。
- **功能**：生成全页深色矢量封面（无外部图片素材）。
- **入参**：无。
- **输出**：NavyDark 底色 + Teal 斜角色块 + 边框 + 标题排版；封面后自动恢复白底。
- **约束**：颜色依赖入口文件配色 token；字号为硬编码，改纸张尺寸需同步调整。

### 【接口：页面样式 study / tocplain / plain】
- **调用方**：`408/main.tex`（`\pagestyle` 按 part 切换）。
- **功能**：
  - `study`：正文样式——左页眉当前节名、右页眉书名、页脚"REVIEW NOTES + 页码"；
  - `tocplain`/`plain`：目录与章节首页的安静样式（无页眉）。
- **入参**：无。
- **输出**：fancyhdr 驱动的页眉页脚组合。
- **约束**：`\sectionmark` 已重定义以显示节名而非章名。

### 【接口：节徽章 sectionbadge】
- **调用方**：`408/main.tex` 的 `\titleformat`（间接被所有 section 使用）。
- **功能**：把节号渲染为 Teal 圆角徽章。
- **入参**：`{节号}`（内部自动传入 `\thesection`）。
- **输出**：tikz 圆角矩形 + 白色节号。
- **约束**：仅视觉层，不改变编号语义。

### 【接口：代码块 lstlisting 定制】
- **调用方**：章节文件（含代码的知识框/习题）。
- **功能**：C 代码高亮、行号、断行、代码内公式混排（`escapeinside`）。
- **入参**：`[language=C]` 等可选参数。
- **输出**：左 Teal 粗线框代码块。
- **约束**：禁用 minted；关键字表已扩展（`LinkList/SqList/ElemType` 等 408 常用类型）。

### 【接口：studybox 基础样式】
- **调用方**：408 侧所有 tcolorbox（内部共享）。
- **功能**：统一圆角、边框、间距、标题字体的基样式。
- **入参**：无（`\tcbset` 定义）。
- **输出**：所有知识框的一致外观底座。
- **约束**：新增知识框类型时先继承此样式再加语义增量，保持"同类框同构"。

## 4. 文档组装接口

### 【接口：part 分卷】
- **调用方**：两书 `main.tex`。
- **功能**：把全书切分为科目/试卷/附录卷，并重置节编号（`\counterwithin{section}{part}`）。
- **入参**：`{卷标题}`。
- **输出**：`\part` 分页 + TOC 一级条目 + 章节重新编号。
- **约束**：新增科目必须同时加 `\part` 与对应壳文件的 `\input`。

### 【接口：科目壳文件】
- **调用方**：`main.tex` → 壳文件（如 `calculus.tex`）→ 章节文件。
- **功能**：序列化 `\input` 章节并强制 `\newpage` 分页。
- **入参**：`\input{<科目>/<章节>.tex}` 一行一个。
- **输出**：按顺序组装的内容流。
- **约束**：停用章节用注释保留（如 `chapt.tex`），不删除——保留恢复路径。
