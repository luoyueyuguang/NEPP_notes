# 07 · 内容编写规范与质量保障

> 面向内容维护者（人类或 AI）：新增/修订章节时必须遵守的规范，以及仓库已有的质量保障体系。
> 规范来源：`local/408-context.md`、两份 `REVIEW.md` 的审阅基准、章节文件的既有惯例。

## 1. 编写规范（408，来自 local/408-context.md）

### 1.1 章节统一结构

1. 概念定义（`mydef` / `attention` 框）；
2. 核心算法/性质（`formula` / `conclusion` 框，含代码）；
3. 基础过关题（6–8 道：单选 + 填空 + 简答）；
4. 真题风格与综合训练（4–6 道，含综合题）；
5. 拓展阅读（标注对应教材精确章节）。

### 1.2 语言与样式要求

- 语言精炼，**不得出现**"王道说""天勤认为"等字样；
- 代码用 C 语言，风格参考邓俊辉教材；
- 408 重点考点用 `attention` 框突出；
- 每章末尾标注教材参考章节；
- 不要用 minted（用 listings）；
- tikz 图用于数据结构（链表、树、图）和组成原理（数据通路）。

### 1.3 教材体系锚点

| 科目 | 主干教材 |
|---|---|
| 数据结构 | 邓俊辉《数据结构（C++语言版）》+ Sedgewick《算法》第4版 |
| 组成原理 | Patterson & Hennessy《计算机组成与设计》+ CS:APP |
| 操作系统 | OSTEP + 陈海波《现代操作系统：原理与实现》 |
| 计算机网络 | Kurose《计算机网络：自顶向下方法》+ 谢希仁（仅术语对齐） |

## 2. 编写规范（数学，从章节惯例归纳）

- 主线范围以考研数学（一）为准；超纲内容（Jordan 标准形、Cayley–Hamilton、Gershgorin、矩母函数、条件期望、充分统计量等）必须标注"拓展阅读/拓展"字样，不进入主线训练；
- 每章结构：知识小节（定义→公式→结论）→ `\newpage` → `\section{习题}`（基础过关题 + 综合提高题）；
- 习题必须给解析（`\boxed{\textbf{解}}` / `\boxed{\textbf{证明}}` / `\boxed{\textbf{答案}}`），且**全部置于 `\ifshowsolutions` 条件块内**；
- 题目标注题型（选择题/填空题/计算题/证明题/简答题/综合题）；模拟卷题目标注分值；
- 命题形式接近真题的题标注"（真题风格）"，**不得标注具体年份/题号**（元数据治理规则）。

## 3. 习题编写硬性约束（质量基准，来自 REVIEW）

| 约束 | 含义 | 违规后果（REVIEW 的处理） |
|---|---|---|
| 题干条件充分 | 可独立作答，不依赖缺失素材 | 改写为自包含文字题 |
| 答案唯一 | 单选不得多解/无解 | 改写题干/选项；无法唯一判断时明示"信息不足" |
| 解析与答案一致 | 解析推导必须导出标注答案 | 独立复算后统一（如 TCP 慢开始 `1,2,4,8,9`） |
| 模型边界明确 | 教材化规则 vs 实现细节不得混写 | 明确"本章统一采用教材化规则；题目指定时例外" |
| 复杂度匹配 | 题干要求与解析算法一致 | 换解法（链表自底向上归并） |
| 数值可核验 | 计算题结果可独立复算 | 代表值入库 REVIEW（Huffman WPL=228 等） |

## 4. 答案闭环工程（408 第三轮的方法，可复用）

408 REVIEW §6.1 记录了"逐题闭环"的完整方法：

1. **静态统计**：按章节统计"题目数 vs 解析标记数"，必须相等；
2. **逐题补齐**：9 个解析不完整的章节共 112 道题，补齐 110 个缺失解析；
3. **防漂移**：检查解析开关是否被子章节重新定义（发现 5 处，已移除）；
4. **独立复算**：对算法过程、状态序列、数值结果做脚本级复算，结果与解析一致才算闭环；
5. **唯一性审计**：选择题逐个确认"恰有一个正确选项"。

## 5. 审阅轮次方法（math 四轮 / 408 多轮的通用模式）

```
第一轮：主干抽查（知识正确性、构建）
第二轮：反向复审（寻找第一轮遗漏，换角度逐科重审）
第三轮：逐题闭环（习题↔解析一一对应 + 静态计数）
第四轮：独立深审（不沿用前轮结论，按章重新检查定义/条件/推导/答案）
```

**每轮必查清单**（从两份 REVIEW 归纳）：
- [ ] 定义的条件完备（如"连续即可推出可微"类错误表述）
- [ ] 公式的适用域与记号统一（Green/Gauss/Stokes 方向约定）
- [ ] 单选题唯一性（多解/无解/条件不足）
- [ ] 综合题题干能否唯一推出答案
- [ ] 数值/序列/状态的独立复算
- [ ] 超纲内容是否标"拓展"
- [ ] 是否残留"必考""真题年份"等违规表述
- [ ] 构建通过：硬错误 0、缺字 0、重复标签 0

## 6. 元数据治理规则

1. 正文题目只能标"真题风格"，不得带年份/题号；
2. 未经逐卷核验的索引文件（`appendix-exams.tex`）**不得**加入 `main.tex` 构建链；
3. 恢复真题索引的最低门槛（appendix-audit.tex 原文）：核对考试年份、题号、学科归属、题型、分值、题面、选项、官方答案、题图完整性，全部与原卷一致；
4. 知识史/标准编号（冯·诺依曼 1945、Dijkstra 1965、PCI 1992、RFC 1918）属于可保留事实。

## 7. 修改内容后的验收清单

- [ ] `xelatex` 双次编译无硬错误（`grep '^!'` 为空）
- [ ] 新习题的解析块位于 `\ifshowsolutions` 内
- [ ] 未触碰/新增任何 `\newif\ifshowsolutions` 局部声明
- [ ] 新 label 全局唯一（编译日志无 `multiply defined`）
- [ ] 新内容无 `Missing character`
- [ ] 习题数 = 解析数（章节闭环）
- [ ] 若改动答案数值，同步 REVIEW.md 的复算记录
- [ ] 无"必考/某年真题"等违规表述
- [ ] 章节文件遵守壳文件组装顺序（新增章节需在壳文件登记）
