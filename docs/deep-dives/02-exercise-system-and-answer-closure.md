## 2. 章节习题的组织模式

### 2.1 数学侧

```latex
\section{习题}
\subsection{基础过关题}    % 概念/计算基本功
\textbf{1.} (选择题) ...
\ifshowsolutions% \boxed{\textbf{解}} ... \fi%
\medskip
\textbf{2.} (填空题) ...
\subsection{综合提高题}    % 证明/跨章节综合
\textbf{7.} (证明题) ...
```

- 题型标记：选择题 / 填空题 / 计算题 / 证明题 / 简答题 / 综合题；
- 综合复习文件（微积分综合复习、alg_review、prob-review、chapt.tex）同样采用此模式；
- 高数 chap9 与综合复习文件是习题大户（16 道/18 道/16 道解析块）。

### 2.2 408 侧

```latex
\section{习题}
\subsection{基础过关题}          % 6-8 道
\subsection{真题风格与综合训练}   % 4-6 道，含综合题
```

- 408 题目明确标注"（真题风格·选择题）"等前缀——"真题风格"指命题形式接近统考，不代表原题；
- OS 综合专题章只有"真题风格与综合训练"一个子节（综合应用题导向）；
- 解析格式：`\ifshowsolutions\par\noindent\textbf{解析：}...\boxed{\textbf{答案：}(B)}\fi`；
- 408 答案以 `\boxed{\textbf{答案：}(字母)}` 结尾，选择题答案显式框出。

## 3. 答案闭环工程（408 第三轮，2026-07-22）

这是仓库质量保障最系统的一次操作，方法可完整复用：

### 3.1 静态计数（发现缺口）

对每个章节统计两类标记：
- 题目数：`\item` / `\textbf{N.}` 计数；
- 解析数：`\ifshowsolutions` 或 `解析：` 标记计数。

结果：9 个章节解析不完整，共 112 道题中 110 道缺解析。

### 3.2 逐题补齐（110 个新解析）

补齐要求（非只列答案字母）：
- 选择题：给出判定过程 + 唯一答案；
- 填空题：给出计算步骤；
- 算法题：给出代码/流程 + 复杂度；
- 综合题：给出可核验的多步推导。

## 4. 选择题唯一性治理

408 REVIEW 记录了完整的处理策略：

| 病症 | 处理 |
|---|---|
| 两个选项同时正确 | 重写选项/题干，保留唯一答案 |
| 无正确选项 | 改写题干，或明示"信息不足" |
| 教材约定冲突（曼彻斯特编码方向、next 数组下标） | 题干显式给出约定 |
| 选项等价（"可逆"与"秩=n"） | 换考点重设干扰项 |
| 答案分布偏斜（集中 B/D） | 选项重排 + 同步答案；分布调至卷一/二 9/11/10/10、卷三 10/10/10/10 |

## 5. 综合题建模纪律（408 高频修订区）

综合题（算法设计、存储/CPU 计算、进程与内存、网络协议计算）最容易出现"题干推不出唯一答案"：

- **时间线题**：必须写明事件时刻、阻塞时长、就绪队列规则、计数口径（OS 综合专题章开头专门立此规则）；
- **算法题**：写明起点、扫描顺序、下标题约（图遍历唯一性依赖起点与邻接点顺序）；
- **模型题**：区分"408 教材化规则"与"TCP Reno 快恢复"等实现细节（cn/chap5 用 `attention` 框集中声明"本章习题统一使用教材化规则"）；
- **参数题**：补足 `a>0`、`b≠0`、`p∈(0,1)` 等定义域条件；
- **硬件题**：写明转发通路、串行计时、淘汰假设（Cache/TLB 延迟题）。

## 7. 质量闭环的持续维护建议

1. **回归门禁**：把"习题数=解析数"静态计数做成脚本，纳入 CI（目前是人工执行）；
2. **复算基线**：REVIEW 中的代表数值应沉淀为可执行测试（脚本断言），内容改动自动触发；
3. **单选唯一性**：可半自动检查——对每个选择题提取选项文本，用规则+LLM 双重判定；
4. **新增习题的验收**：遵循 `07` 文档验收清单，特别是"解析必须在开关内"与"label 唯一"。
