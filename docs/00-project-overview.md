# 00 · 项目总览

> 本文档面向首次接触本仓库的人类读者与 AI 读者，回答四个问题：这是什么、包含什么、如何构建、如何阅读。

## 1. 项目是什么

**NEPP_notes** 是一套以 LaTeX 编写的考研复习讲义仓库，包含两本独立的书：

| 书 | 名称 | 对应考试 | 学科 |
|---|---|---|---|
| 数学 | luoyue's Math Notes | 考研数学（一） | 高等数学、线性代数、概率论与数理统计 |
| 408 | 408 计算机学科专业基础综合 | 计算机统考（408） | 数据结构、计算机组成原理、操作系统、计算机网络 |

两本书共享同一套工程底座（XeLaTeX + ctexbook + tcolorbox 知识框体系），但在排版风格、习题组织方式、视觉设计上各自独立演化。

**内容来源声明（仓库 README 原文）**：本项目内容完全由 AI 生成，仅供学习参考，不负任何准确性、完整性或可靠性责任。数学部分在编写中参考了李正元老师的复习全书等资料；408 部分参考了邓俊辉《数据结构（C++语言版）》、Sedgewick《算法（第4版）》、Patterson & Hennessy《计算机组成与设计》、CS:APP、OSTEP、陈海波《现代操作系统：原理与实现》、Kurose《计算机网络：自顶向下方法》与谢希仁教材（仅术语对齐）。

## 4. 核心技术特征

1. **单一入口 + 分卷组装**：两本书都以 `main.tex` 为唯一入口，用 `\part` 分卷、`\input` 按科目聚合章节文件；章号由 `\counterwithin{section}{part}` 实现"每部分重新编号"。
2. **tcolorbox 知识框体系**：`mydef`（定义）、`formula`（公式/要点）、`conclusion`（结论）、`attention`（考点警示）、`examplebox`（例题）、`tablebox`（表格）六类框，统一学习材料的视觉语义。
3. **习题/解析双版本机制**：`\ifshowsolutions` 条件开关贯穿全书。关闭后生成纯题目版 PDF（刷题不泄题），开启后生成题目+解析版（订正用）。2026-07-31 起通过 GitHub Release 同时发布两个版本。
4. **真题风格 vs 真题的元数据治理**：未经逐卷核验的年份/题号一律不进入正式构建链；正文题目统一标注"真题风格"（`appendix-exams.tex` 被隔离，`appendix-audit.tex` 说明原因）。
5. **审阅闭环作为工程资产**：`math/REVIEW.md`（四轮）与 `408/REVIEW.md`（多轮）记录了从"全书初版"到"逐题闭环"的全部修订证据，包括独立复算的代表性数值。
6. **CI 质量门禁**：push/PR 时自动构建 math 版 PDF，检查硬错误、缺字、重复标签三类问题。

## 5. 可见风险与边界

- **准确性边界**：两份 REVIEW 均明确声明"不能证明绝无错误"，且未与 2027 新大纲逐条对照；2027 大纲发布后需增量复核。
- **题源边界**：真题年份/题号未完成权威核验，正文只作"真题风格"题训练，不能当作真题索引。
- **CI 覆盖缺口**：构建流水线只覆盖 math，408 的自动构建与质量检查尚未纳入 CI。
- **排版遗留**：构建日志中仍存在一定量的 Overfull/Underfull hbox 警告（均为非致命）。
- **内容体量**：数学部分含少量超纲拓展（Jordan、Cayley–Hamilton、矩母函数等），已在正文标注"拓展"，不应纳入主线备考负担。
